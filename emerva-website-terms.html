3. YouTube API

Программа работает с собственным ключом YouTube Data API каждого пользователя. Использование должно соответствовать условиям YouTube API Services Terms of Service и Google Privacy Policy.

4. Данные

Найденные каналы и настройки хранятся локально на устройстве пользователя. Приложение не передаёт эти данные на сервера автора.

5. Ответственность за использование контактов

Найденные email и Telegram — публичная информация, размещённая самими владельцами каналов. Пользователь самостоятельно несёт ответственность за соблюдение антиспам-законодательства при обращении к ним.

6. Тарифы и оплата

Оплата подписок Pro и No Limit принимается через сторонние платёжные сервисы (карта — через партнёра-продавца записи; криптовалюта — через Telegram-сервис оплаты). Emerva Tools не хранит и не обрабатывает данные банковских карт напрямую.

Подписка активируется после подтверждения оплаты выбранным способом. Возврат средств рассматривается индивидуально по обращению в поддержку.

7. Вход через Telegram и Google

При входе через Telegram или Google приложение получает только базовые данные профиля (имя, юзернейм, аватар) для персонализации интерфейса и привязки тарифа к аккаунту.

Автор может обновлять эти условия. Актуальная версия всегда доступна на этой странице.
